# 漚汪國小探索園區｜火車穿梭蘿蔔田 3D 校園特色互動模型

本專案參考「**南大附中探索群島**」（`https://tntcshisland.vercel.app/`）之溫暖手作微縮模型設計概念，並針對**臺南市將軍區漚汪國民小學**（Ouwang Elementary School）在地「胡蘿蔔之鄉」與百年糖鐵文化量身打造 **「火車穿梭於紅蘿蔔田中的 3D 校園特色互動模型」**，完整整合 [漚汪國小校園特色網](https://sites.google.com/owes.tn.edu.tw/school-highlights/%E9%A6%96%E9%A0%81) 八大架構、25 張實景活動相片、111–114 學年度榮譽榜，以及 [漚汪國小媒體報導專區](https://www.owes.tn.edu.tw/modules/school/index.php?op=all_links) **全數 4 頁共 66 篇真實新聞報導與 3 個延伸特色網站**。

---

## 🌟 核心設計特色

1. **火車穿梭紅蘿蔔田 3D 微縮模型架構（`scene3d.js`）**
   - **將軍區紅蘿蔔田柔和微縮景觀**：大地底座鋪設 24 座立體紅蘿蔔田壟、超過 500 株飽滿橘紅蘿蔔與翠綠羽狀葉、田間風車與木棧步道；白天採用溫潤柔和的日光色調與紙感材質（避免刺眼反光）。
   - **「漚汪號」蒸汽糖鐵小火車（悠閒慢速巡航）**：沿著 3D 閉合環狀鐵軌（含 220 根木枕與雙鋼軌）悠閒穿梭於紅蘿蔔田與八大校園特色車站之間。火車包含蒸汽火車頭（動態白煙粒子、車頭探照燈）與 3 節主題車廂（滿載將軍紅蘿蔔、書本與 PBL 創客積木、揮手小書童）。
   - **左側「🚂 校園特色車站清單」滑出導覽面板**：可隨時收合／展開左側清單，一鍵飛往八大特色車站、啟動「追火車視角」或開啟「📰 媒體報導分類總覽（66 篇）」。

2. **完整整合「漚汪國小校園特色網」八大深度架構（`data.js`）**
   - 每座車站皆具備 **「介紹、深度專題、相片花絮、歷年榮譽、📰 媒體報導」** 五大頁籤，內含深度專題卡（`deepDive`）、相片圖說故事、課程時數／獲獎圖表與對應新聞報導。

3. **完整收錄並分類整理「漚汪國小媒體報導專區」66 篇新聞（`data.js` / `app.js`）**
   - 完整擷取校網媒體報導第 1～4 頁全部 **66 篇新聞連結**（涵蓋中華日報、臺灣時報、自由時報、國語日報、聯合新聞網、中時新聞網、ETtoday 新聞雲、臺南市政府、廣達文教基金會、民眾網、Yahoo 新聞共 11 家媒體），並歸納為 **六大主題分類**：
     1. 🥕 **食農遊學與生態環境**（將軍紅蘿蔔食農、牛蒡採收、通學步道、校園老樹、黑面琵鷺環教）
     2. 💡 **課程創新與家鄉走讀**（廣達設計學習 PBL、許獻平老師繪本說書、文衡殿老街踏查、德國國際筆友）
     3. 💛 **品格教育與謝師祈福**（教師節古禮束脩敬師、母親節奉茶、文衡殿畢業祈福、模範兒童與家扶自強兒童）
     4. 🎨 **藝文雙語與體育競賽**（ICRT 英語廣播、大台南天然氣繪畫比賽、太鼓隊、飛盤爭奪賽、小小解說員）
     5. ❤️ **公益關懷與校友回饋**（跳蚤市場義賣捐助家扶與華山、戴榮吉百歲獎學金、林崑海遺愛、校友球衣與車票捐贈）
     6. 🏫 **110 校慶與校園盛事**（創校 110 週年校慶聖火繞境、三代同堂、兒童節上下課翻轉、新生入學禮）
   - 同步整合 **「漚汪設計學習成果網（PBL）」** 與 **「漚汪 SEL 社會情緒學習網」** 兩大延伸主題網站入口。
   - 提供 **「📰 媒體專區全頁分類總覽」** 與 **「各車站專屬媒體報導分頁」** 雙重檢視方式，支援主題分類篩選、11 家新聞媒體篩選、關鍵字即時搜尋與一鍵跳轉對應 3D 車站。
